# AI/ML Resume Analyzer

An AI/ML-based web application that analyzes a resume against a job description.

## Features

- Upload PDF/DOCX resume
- Resume text extraction
- Skill detection
- Job skill matching
- ATS keyword analysis
- Resume scoring
- NLP similarity analysis
- Improvement suggestions
- PDF report generation

## Technologies

- Python
- Streamlit
- Scikit-learn
- NLP
- PyPDF
- python-docx
- ReportLab
